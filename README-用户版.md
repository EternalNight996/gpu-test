# gpu-test 显卡功能性测试 · 用户说明

> 版本：Rust 版 ｜ 适用：Windows 10/11、Ubuntu 18.04+、麒麟 V10、统信 UOS V20

由 e-autotest 测试平台自动调用，检测工位显卡是否正常，自动拦截不良显卡。
本工具只提供三样东西：**测试、返回数据、日志**。

## 一、测试内容

| 步骤 | 检查项 | 不通过代表什么 |
|---|---|---|
| 1 | 系统能否枚举到显卡（Windows 设备管理器 / Linux `lspci`） | 显卡不识别或 PCI 枚举异常 |
| 2 | NVIDIA 独显的驱动与 `nvidia-smi` 是否正常 | 驱动未装、加载失败或驱动层异常 |
| 3 | `nvidia-smi` 连续采样 N 次（默认 3 次）是否全部正常 | 概率性丢失、间歇性不识别 |

判定规则：

- 有 NVIDIA 独显：任何一项异常 → **FAIL 拦截**。
- 只有核显（无 NVIDIA 独显）：**PASS**，不误杀核显机型。
- 完全检测不到显卡：**FAIL**，显卡未被系统识别。

## 二、返回数据

每次检测返回一行标准数据（e-autotest 格式）：

```
R<{"content":"检测到显卡设备 2 个: ... PASS: 显卡硬件识别正常，驱动已加载，nvidia-smi 采样 3 次全部正常","status":true,"opts":{...}}>R
```

- `status: true` = 通过（PASS），退出码 0
- `status: false` = 拦截（FAIL），退出码非 0
- `content` 为检测明细；失败时写明原因（枚举结果 / nvidia-smi 状态 / 采样失败次数）

另有型号标识接口 `--info`，单独返回显卡标识（如
`GPU 0: NVIDIA GeForce RTX 3060 [10de:2487] 驱动:610.62 显存:12288 MiB VBIOS:94.04.71.00.c2 WMI驱动:32.0.16.1062`），
供平台按"首件基准 vs 量产"比对是否一致，不一致判 NG。
保留字段：型号 + 设备 ID + 驱动版本 + 显存 + VBIOS；PCI 位置、UUID 不参与比对。

## 三、日志

每次运行自动追加写入 `logs/gpu-test.log`（程序所在目录的 `logs` 文件夹），
并同步在屏幕（stdout）输出同样格式的详细日志，
**显卡功能性测试全流程分步记录，每条带时间戳**：

- 运行开始（SN/工站/模式/采样次数）
- 硬件枚举：逐张显卡记录
- 显卡功能：驱动与 `nvidia-smi` 检查
- 稳定性采样：每一次采样结果
- 最终判定，末尾附一行 `R<...>R` 返回数据

不良显卡反馈时，附上该日志即可定位。
