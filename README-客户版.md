# gpu-test 显卡功能性测试 · 方案说明（客户版）

> 适用平台：Ubuntu 18.04+ / 银河麒麟 V10 / 统信 UOS V20 / Windows 10/11 ｜ 接入 e-autotest 测试平台

## 一、背景与改善前状况

IPC KA 客户 2026 年 1–8 月已反馈 17 块盈通显卡不良（开箱 + 终端），不良率 5324 DPPM。

改善前产线测试程序不包含显卡功能性测试，以下不良无法在工厂拦截：

- 显卡完全不识别、概率性不识别
- 驱动未装 / 加载失败 / 驱动层异常
- `nvidia-smi` 偶发丢失、间歇性故障

**改善前的弊端：**

- 依赖人工目检，漏检风险高，不良品直接流出到客户
- 开箱即坏导致客户产线停线，处理成本高
- 无检测数据留档，问题追溯困难
- 反复退换影响交付信誉

## 二、改善措施（改善后）

测试工位新增 **gpu-test 显卡功能性测试**，接入 e-autotest 平台自动执行：

| 步骤 | 检查项 | 不通过 |
|---|---|---|
| 1 | 系统枚举显卡（Windows 设备管理器 / Linux `lspci`） | 显卡不识别 → **FAIL 拦截** |
| 2 | NVIDIA 驱动与 `nvidia-smi` 可用性 | 驱动异常 → **FAIL 拦截** |
| 3 | 功能自检：利用率/功耗/温度/时钟响应 | GPU 功能不存活 → **FAIL 拦截** |
| 4 | `nvidia-smi` 连续采样 N 次（默认 3 次） | 概率性丢失 → **FAIL 拦截** |

判定：有 NVIDIA 独显时任一异常即拦截并报明细；核显机型 PASS，不误杀。
每次检测返回标准数据（`R<...>R`）并写入日志，全程可追溯。

### 型号一致性比对（首件 vs 量产）

- **首件**：首件运行时通过 `--info` 接口读取显卡标识（型号 + PCI 设备 ID + 驱动版本 + 显存 + VBIOS，
  如 `NVIDIA GeForce RTX 3090 [10de:2204] 驱动:610.62 显存:24576 MiB VBIOS:94.04.71.00.c2`；
  PCI 位置、UUID 量产会变，不参与比对）
- **一键同步**：将该标识一键填入平台"校验筛选"，作为基准
- **量产**：每台自动比对型号标识，与首件不一致 → 自动判 **NG 拦截**，防止换卡/错卡/不良卡流入

## 三、改善前后对比

| 项目 | 改善前 | 改善后 |
|---|---|---|
| 显卡功能性测试 | 无 | 自动检测（枚举 + 驱动 + 稳定性采样） |
| 不良拦截 | 无法自动拦截 | FAIL 自动拦截，不流入下工序 |
| 检测数据 | 无记录 | `R<...>R` 标准返回 + 逐台日志留档 |
| 人工依赖 | 目检 | 自动化，降低人工漏检 |
| 单台测试耗时 | 0 | 增加约 3~5 秒（采样次数可调） |
| 漏检风险 | 高 | 显著降低 |
| 质量追溯 | 困难 | 日志含 SN/工站/结果，快速定位 |

## 四、改善后的弊端与局限

- 单台测试时间增加约 3~5 秒（可用 `--samples` 调整，采样越多越严、耗时越长）
- 依赖系统识别环境：Linux 需 `lspci`，NVIDIA 场景需驱动与 `nvidia-smi` 正常安装
- 驱动拦截仅针对 NVIDIA 独显；核显机型默认 PASS，不做拦截
- 概率性故障通过多次采样提高检出率，无法保证 100% 覆盖
- 日志与检测依赖工位程序工作目录可写（`logs/` 文件夹）

## 五、效益

- **降低不良流出**：未识别 / 驱动异常 / 概率性丢失显卡在工厂即被拦截，DPPM 有望显著下降
- **减少客诉与停线**：开箱不良减少，客户产线更稳定
- **降低成本**：减少退换、返修与重测成本
- **可追溯**：每台检测结果与日志留档，问题定位从"猜"变"查"
- **提升质量信誉**：交付前多一道自动化拦截，客户满意度提升

## 六、返回数据与日志

检测结果（示例）：

```
R<{"content":"检测到显卡设备 2 个: ... PASS: 显卡硬件识别正常，驱动已加载，nvidia-smi 采样 3 次全部正常","status":true,"opts":{...}}>R
```

- `status: true` = 通过，退出码 0；`status: false` = 拦截，退出码非 0
- 失败时 `content` 含明细：枚举结果 / nvidia-smi 状态 / 采样失败次数

日志：每次运行追加写入 `logs/gpu-test.log`，**显卡功能性测试全流程分步记录**（运行开始 → 硬件枚举逐卡 → 驱动/nvidia-smi → 稳定性每次采样 → 最终判定），每条带时间戳，末尾附 `R<...>R`。
